设置

外观模式
切换界面明暗配色；「跟随系统」随 Windows 深浅色模式自动变化
主题色
为按钮、选中项和浮窗搭配统一色系，支持深浅模式
自定义
界面缩放比例
100% 跟随 Windows 系统缩放，不额外放大。可调整界面整体元素大小，适用于高 DPI 屏幕使用较高系统缩放时觉得界面偏大的情况；可从下拉选档位或直接键入任意百分比，更改后需重启应用生效
小爱同学悬浮对话按钮
启用位于主界面右下角的小爱同学对话悬浮按钮（需设备里有小爱音箱）
显示场景选项卡
在主页房间选项卡左侧显示「场景」入口，可一键执行米家 APP 中创建的手动场景
开机自启动
开启后，Windows 登录时自动启动米家（可与「以系统托盘方式启动」搭配静默运行）
默认指挥的音箱
小爱语音指令默认发往的音箱；选择「自动」时使用设备列表中第一个在线音箱
带快捷操作面板的系统托盘
开启后，关闭主窗口时将最小化到系统托盘并启用托盘快捷操作面板
以系统托盘方式启动
开启后，启动软件时将以系统托盘的方式静默启动，不唤出主界面（该功能需开启系统托盘功能可选）
隐藏无可控制功能的设备
无公开功能规格或规格无属性的设备（如部分蓝牙类产品）将不在主页显示
自动检测新版本
开启时，会在每次启动应用时自动从 Github 仓库获取新版本信息，有则提示更新
内置 Pi Agent 引擎
模型引擎
内置本地引擎免 API Key 即可执行常见开关、调光、温湿度与喂食器操作；也可接入主流云端大模型或自定义网关
自定义提供商名称与 API 协议
可为自定义网关命名（如 magpie、ollama），并选择对应的接口协议
API Base URL（可选）
留空使用默认官方地址；接入本地 Ollama（如 http://127.0.0.1:11434/v1）或代理网关时填写
API Key
密钥仅保存在本机配置文件，绝不向前端回传明文；也自动支持环境变量（如 DEEPSEEK_API_KEY / OPENAI_API_KEY）
模型列表与模型 ID
配置 API 地址与密钥后将自动从接口拉取可用模型列表，也可手动输入自定义模型 ID
本地快路径（常规指令本地优先）
配置云端或自定义大模型时，开启后常见确定性智能家居指令（如开关设备、调光、调音量、停播音乐）将优先走零延迟本地规划引擎；关闭则统一交由当前大模型理解与执行（默认关闭）
语音与文字回复风格
自然口语且简洁，保留基本礼貌与完整句式 · 例：“好的，客厅吸顶灯已经打开，亮度调到85%了。”
附加指令规则（支持语音保存多条 · 冲突时最新优先）
直接对语音助手说“以后记得洗衣默认用智洗烘模式”或“以后我说打开空调你要自己判断室外温度，根据室外温度自动选择对应正确的模式和温度”即可自动保存；多条规则若存在冲突，始终以最新一条为准。
语音监听、环境降噪、声纹与注意力设置
本地离线语音 AI 引擎状态（Qwen3-ASR GPU/CPU · Sherpa-ONNX）
本地离线运行 Qwen3-ASR-0.6B（主，自动识别 GPU 加速 / CPU 兜底）与 SenseVoice（备用）多语种识别、GTCRN 降噪、Silero VAD、3D-Speaker 声纹与 openWakeWord 唤醒
Qwen3-ASR 0.6B (主) GPU 加速 SenseVoice (备用) GTCRN 降噪 DPDFNet4 强噪 VoxLock 声纹提取 Silero VAD 3D-Speaker 声纹 openWakeWord 唤醒 Matcha 温柔女声
语音识别引擎
「自动」优先本地离线 Qwen3-ASR-0.6B（主）/ SenseVoice（备用）+ GTCRN 降噪 + 声纹管线，未就绪时自动降级云端 STT 或浏览器原生识别
本地语音转写方案
默认使用 Qwen3-ASR-0.6B 作为主方案提升中英转写准确率，主模型未就绪或异常时自动无缝切换至 SenseVoice 储备方案
Qwen3-ASR 推理设备（自动识别 GPU）
自动检测本机独立/集成 GPU 并优先在 GPU 上加速运行 Qwen3-ASR-0.6B；无可用 GPU 或显存不足时自动无缝回退 CPU
Qwen3-ASR 流式转写与智能断句
开启后说话期间实时逐字流式转写并智能断句（句末标点+短停顿快速收句、唤醒词防误拆，兼容 GPU / CPU / 备用引擎）；关闭则恢复传统静音判停整句转写
识别语言
用于本地 Qwen3-ASR / SenseVoice、Whisper 转写与浏览器语音识别
环境降噪、抗音乐干扰与语音端点检测（VAD）
AudioWorklet 实时直推 16kHz PCM 至服务端在线降噪 + 流式 Silero VAD + 双轨抗音乐识别，避免背景音乐下人声被门限吞掉或 15 秒卡顿
ms 判停
启用唤醒词过滤
开启后仅响应定向呼唤助手的语句；关闭后持续监听到的每句话都会直接交给 Pi Agent
自定义唤醒词与 openWakeWord 声学唤醒
多个唤醒词用逗号分隔（支持中英文与自定义词，如 Neo、小派）；命中唤醒词后进入持续对话，超时无声自动退回待唤醒
秒对话
触发唤醒词后的语音应答短语，默认为「嗯?」；清空并留空则不语音回复，直接静默持续监听。
阈值
可为任意自定义唤醒词录制 2~3 条真人样本提升准确率，或点击「重新合成」快速生成模板
SystemOne 智能决策门控（防误触与旁白过滤）
在对话模式中实时判断语音是在下达指令还是他人旁白，连续旁白达上限自动退回待唤醒
次旁白退出
声纹识别与说话人管理（3D-Speaker CAM++）
注册声纹后可识别当前说话人身份，或在严格模式下仅响应主人/家庭成员，防止电视与陌生人误操作
阈值
温柔女声语音播报与语音打断（Barge-in）
默认使用本地离线 Matcha 神经温柔女声流式播报，零卡顿、自然悦耳；右侧可控制是否允许说话打断
语速
可选 STT 语音转写服务（OpenAI Whisper 兼容）
当国内无法使用 Chrome 在线识别或使用 Firefox 时，可配置 SiliconFlow (SenseVoiceSmall) / OpenAI / 本地 faster-whisper 地址

从托盘快速操作 MijiaDeck

  • 单击或双击托盘图标：打开 / 收起快捷浮窗
  • 右键托盘图标：打开菜单，选择「显示主窗口」
  • 鼠标经过图标不会再弹窗。开启托盘常驻时，关闭主窗口仍可从托盘操作。
  • 找不到图标？请点击任务栏右侧的「显示隐藏图标」按钮。
关于 MijiaDeck

MijiaDeck

版本 v1.1.2

米家设备的桌面控制端：扫码登录米家账号后，在本地窗口中查看与控制家里全部米家设备——设备卡片快速开关、灯光控制、摄像头远程预览、系统托盘快捷控制、小爱语音指令与深浅色主题。

开源致谢

本项目基于 MiHome-Windows 改进，参考 mijiaAPI 连接米家设备，使用 Bun + TypeScript 构建，遵循 GPL-3.0-or-later 开源协议。
